# Лабораторная работа №1 — подготовка данных

## Результат

- Исходная форма: **569 × 32**.
- После очистки: **569 × 33** (включая бинарный target).
- Пропусков до обработки: **0**.
- Полных дубликатов измерений удалено: **0**.
- Классы: benign — **357**, malignant — **212**.

## Принятые решения

ID не используется как признак. Диагноз закодирован как `B=0`, `M=1`.
Числовые признаки стандартизированы с помощью StandardScaler в отдельной таблице.
Наблюдения за границами 1.5×IQR отмечены в аудите, но не удалены и не обрезаны:
экстремальные клинические измерения могут быть корректными и важными для диагноза.

Очищенные данные сохранены в `data/processed/breast_cancer_clean.csv`,
стандартизированные — в `data/processed/breast_cancer_standardized.csv`.
