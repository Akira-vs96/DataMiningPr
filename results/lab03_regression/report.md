# Лабораторная работа №3 — линейная регрессия

Модель прогнозирует `worst_radius` по `mean_radius` на независимой тестовой выборке
20% (random_state=42).

Уравнение: **worst_radius = -2.3822 + 1.3187 × mean_radius**.

- R² = **0.9425**;
- adjusted R² = **0.9420**;
- RMSE = **1.1788**;
- VIF единственного предиктора по определению равен 1.

Коэффициент описывает среднее изменение worst radius при увеличении mean radius
на единицу. Это ассоциативная прогнозная модель, а не причинное заключение.
