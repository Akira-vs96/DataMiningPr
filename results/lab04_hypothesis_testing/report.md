# Лабораторная работа №4 — проверка гипотез

H₀: средние значения `mean_radius` в benign- и malignant-группах равны.
H₁: средние значения различаются.

Welch t-test: t = **-22.2088**, p = **1.684e-64**;
при α=0.05 нулевая гипотеза **отвергается**. Непараметрический Mann–Whitney
также рассчитан как проверка устойчивости вывода (p = 2.693e-68).

Размер эффекта Hedges g = **2.2025** (положительный знак означает большее
значение в malignant-группе). Welch-вариант выбран заранее, поскольку он не
требует равенства дисперсий.
